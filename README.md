# ⌨️ Shell UI

> *The fleet's browser-based work surface — shell, filesystem, fleet health.*

A single-page web interface for the Terax Gateway. Zero build step — open in any browser.

## Features
- **Shell** — Run commands, see output in real-time
- **Filesystem** — Browse directories, read files
- **Fleet** — Service health, casting-call model selection
- **Processes** — List, view logs, kill background processes

## Usage
Open `index.html` in a browser with the gateway running on port 8410.

## Dependencies
None. Pure HTML + CSS + JS, no build step.
